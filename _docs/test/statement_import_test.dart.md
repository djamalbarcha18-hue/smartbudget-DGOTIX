## Overview

This file is a Dart test suite exercising the statement import and table reading functionality used by the application. It defines a local helper (readCsv) that converts CSV text into a SheetTable via TableReader, runs StatementParser.guess to detect header/column layouts, and then calls StatementParser.read to produce StatementRead objects for assertions. The tests cover CSV parsing edge cases (quoted fields, different separators, legacy encodings), workbook detection and size limits, and parsing of bank statement formats (various languages, date and number formats, signed vs unsigned amounts, and columns that indicate credit/debit). Several tests validate that parsed StatementRow entries have the expected dates, amounts, transaction types, categories, and unreadable-row counts.
