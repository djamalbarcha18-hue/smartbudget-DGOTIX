## Overview

This directory contains shared AI integration code used by serverless functions. At the root level it provides a gateway module (gateway.ts) that implements a gateway layer responsible for selecting and invoking AI model providers for different task types. The gateway module is intended to be the central entry point for routing AI requests to the appropriate provider implementation.

Alongside the documented gateway module, there are other files present in this directory (budget.ts, budget_test.ts, gateway_test.ts) which are listed but not documented here; they may contain budgeting logic and tests related to the AI integrations. Together, the gateway and those adjunct files form a focused area responsible for AI provider selection, invocation, and related verification/testing utilities used by higher-level functions. This directory's role in the larger system is to encapsulate provider selection and invocation logic so serverless functions can rely on a single shared gateway layer for AI tasks without each function reimplementing provider management.


### File Organization

Files are organized around a shared runtime layer for AI functionality. The primary runtime entry is the gateway module which acts as an integration layer between function handlers and AI model providers. Related concerns such as budgeting and tests exist alongside the gateway but are maintained as separate modules to keep responsibilities separated.

- A gateway layer centralizes AI provider selection and invocation, allowing serverless functions to remain provider-agnostic.
