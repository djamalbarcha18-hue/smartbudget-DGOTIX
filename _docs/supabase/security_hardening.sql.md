## Overview

This SQL file applies security-hardening measures and runtime guards for the SmartBudget database. It introduces atomic usage reservation and release functions (reserve_usage and release_usage) that serialize per-user usage checks with advisory locks, enforce per-user and platform-wide monthly and lifetime limits for AI requests and OCR scans, and update corresponding monthly and lifetime usage tables. The file also restricts direct client manipulation of profile data, ensures webhook ordering by adding a provider event timestamp column to subscriptions, and enforces a maximum size for cloud backup payloads via a table check constraint.

In addition to the procedural logic, the script adjusts privileges so only the Edge Functions (service_role) can execute the usage reservation/release functions, limits insert/update/delete rights on profiles for anonymous/authenticated roles while granting a specific subset of update columns to authenticated users, and creates supporting indexes for monthly usage aggregates. These changes are intended to be safe to re-run and to be applied after the other schema and function definitions are in place.
