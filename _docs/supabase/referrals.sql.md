## Overview

This SQL file implements a referral system for a Supabase-backed application. It defines tables to store one referral code per user (referral_codes), a single record for each invited account linking the invitee to their referrer (referrals), and a table of rewards granted to users (reward_grants). The file provides SQL and PL/pgSQL functions to enumerate available rewards, compute how many reward picks a referral count entitles a user to, create or return a caller's referral code, record a claim of a referral code by a newly created account, and mark an invited account as activated when they confirm their email. Access is restricted so clients can only read their own referral codes and granted rewards; writes are performed via the provided functions running with defined security settings.
