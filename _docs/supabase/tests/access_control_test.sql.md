## Overview

This SQL file implements an automated suite of access-control tests that run against a Supabase-style schema. It seeds test accounts and sample rows for transactions, backups, subscriptions, entitlements, usage, and related billing and logging tables, then switches to an authenticated role with a configured JWT subject to simulate a signed-in user. A temporary results table and a PL/pgSQL helper function (pg_temp.attempt) are created to execute statements, capture whether each attempt succeeded or was denied, and record PASS/FAIL outcomes along with brief diagnostics.

The remainder of the file runs many individual test cases by invoking the helper, exercising reads, writes, updates, and deletes across user-scoped and global tables to verify row-level security and permission constraints. Tests include attempts to access or modify other users' data, create or change subscriptions and entitlements, reset usage counters, call resource-reservation functions, and inspect billing and coupon data; each attempt expects either a denied result or a specific number of affected rows and is recorded in the temporary results table.
