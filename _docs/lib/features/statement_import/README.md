## Overview

This directory groups the feature for importing tabular statement data into the application's in-memory representations. At the root level it organizes submodules rather than exposing many root-level implementation files; the documented domain subdirectory contains the core logic to read tabular sources (CSV/TSV and Excel .xlsx) and convert them into an in-memory SheetTable representation via utilities such as table_reader.dart.

The directory is intentionally structured into subdirectories: domain/ holds the parsing and table-reading domain logic (including a table_reader.dart utility described at the root of that subdirectory), and presentation/ is present to contain UI- or presentation-related code for statement import (not documented here). Together these components separate concerns: domain code performs file-format handling and conversion into SheetTable objects, while presentation code consumes those domain objects to drive UI flows or higher-level import orchestration. This layout helps consumers find parsing logic in domain/ and presentation concerns in presentation/.


### File Organization

Files are organized by responsibility into subdirectories. The domain/ subdirectory contains domain-level parsing and SheetTable construction utilities (table_reader.dart). Presentation-related code is placed under presentation/. The root of this directory serves as a feature boundary rather than a flat file area.
