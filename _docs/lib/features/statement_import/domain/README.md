## Overview

This directory contains domain-focused code used to import tabular statement data into the application's in-memory SheetTable representation. At the root level, table_reader.dart provides utilities to read tabular data from CSV/TSV-like text files and Excel .xlsx workbooks and convert those inputs into the SheetTable form used by downstream processing.

In addition to the documented table_reader.dart, there are other domain files (for example statement_parser.dart is present but not documented here) that participate in parsing and interpreting statement data. Together, these files implement the domain logic for ingesting different tabular formats, normalizing them into a consistent SheetTable model, and making that model available to higher-level features in the repository. This directory therefore acts as the domain-layer bridge between raw input files and feature-level processors that operate on statements.


### File Organization

Files in this directory are organized by domain responsibility: utilities that perform data ingestion and domain-level parsing live here. Root-level files provide core conversion from external tabular formats into the internal SheetTable representation. Related parsing or interpretation files (e.g., statement_parser.dart) co-reside in the same directory and implement additional domain logic.
