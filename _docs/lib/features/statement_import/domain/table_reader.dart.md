## Overview

This file provides utilities to read tabular data from either CSV/TSV-like text files or Excel .xlsx workbooks into an in-memory SheetTable representation. SheetTable is a small immutable-like container for rows of cell text and a set of positions that should be treated as numeric values. TableReader is a static utility surface that detects file type, decodes text with consideration for common encodings and code pages, parses CSVs (including quoted fields and automatic separator detection), and contains logic to open and sanity-check .xlsx ZIP packages and extract the first worksheet as rows and cells. The file also defines TableError and TableReadException to communicate why a file could not be read (for example old .xls format or generally unreadable input).
