## Overview

This file provides a web-only implementation of file input/output operations for the browser environment. It exposes utilities to trigger browser downloads of text and binary data, and to open the browser file picker to read selected files as either text or bytes. The implementation is built on top of the web package and the browser DOM/File APIs, handing blobs to the browser for download, using an input element to invoke the file picker, and using a FileReader to read chosen files back into Dart as text or an ArrayBuffer.

The module enforces a maximum accepted file size for picked files and encodes text downloads via Blob to preserve UTF-8 content. Utility functions are asynchronous where appropriate, returning null when the user cancels the picker or when the selected file is too large or cannot be read in the requested form.
