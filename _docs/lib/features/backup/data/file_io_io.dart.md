## Overview

This file provides mobile-oriented file input/output helpers that integrate with the system file picker and save dialog. It exposes convenience functions to save text or binary data by invoking the platform "save as" UI, and to let the user choose a file to read either as UTF-8 text or as raw bytes plus its filename. The implementation uses the FilePicker package and encodes/decodes text with UTF-8; it also enforces a maximum size for picked files and tolerantly handles errors and cancelled operations by returning null or swallowing exceptions.
