## Overview

This directory groups the code that implements the application's backup feature. At the root level there are platform-specific I/O helpers located under the data/ subdirectory: those documented files provide two concrete implementations and helpers for file input/output operations used by the backup feature, including a mobile-oriented helper that integrates with the system file picker and save dialog and a web-oriented implementation. No specific root-level files are documented in the provided context; instead the concrete I/O implementations live under data/ and serve as the platform integration layer for reading and writing backup payloads.

In addition to data/, this directory contains three feature sublayers — application, domain, and presentation — which are present but not documented in the provided context. Collectively these subdirectories are intended to form the full backup feature: data/ provides the platform I/O and helpers used to persist or restore backup files, domain/ would contain core business rules and models for backup payloads, application/ would host use cases or orchestration logic that coordinate backup flows, and presentation/ would provide UI or input handlers that trigger backup/export/import flows. The components work together by having presentation trigger application use cases, which rely on domain models and call into data layer implementations to perform file I/O on the current platform.


### File Organization

The directory is organized by feature and sublayers. Platform-specific file I/O implementations and helpers live under data/. The feature also exposes application, domain, and presentation subdirectories to separate use cases, business logic, and UI concerns. Root-level files are not documented in the provided context; primary implementations are inside data/.
