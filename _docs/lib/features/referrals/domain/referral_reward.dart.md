## Overview

This file defines the referral reward model and the logic used to interpret how granted referral rewards affect product features. It declares an enum of server-known rewards (ReferralReward) with stable string identifiers that match the server schema, and a final abstract utility class (ReferralRewards) that codifies the referral program rules: how many referrals are required, a temporary welcome-gift window for invited users, which rewards outright unlock locked features, and which reward grants increased limits for count-limited features.

The ReferralRewards class exposes purely static constants and helper methods to compute gift expiry, check whether a gift is active, map rewards to opened features, compute raised allowances for specific features, and produce the list of features impacted by a reward. These members are designed to be consumed by higher-level billing or feature-checking code so the app can decide whether a given set of granted rewards should open features or increase limits for the current user.
