## Overview

This directory contains the domain-layer implementation for the referrals feature, focusing on the representation and interpretation of referral rewards. At the root level the documented file referral_reward.dart defines the referral reward model and the logic used to interpret how granted referral rewards affect product features. That file encapsulates the rules and transformations that map reward data into feature-impacting outcomes, making it the central business-logic artifact in this directory.

There are additional files present in this directory (referral_link.dart, reward_journey.dart) which are listed but not documented here; they likely relate to other domain concepts within referrals such as link handling and the reward lifecycle. Together, these domain artifacts coordinate to represent referral entities, the lifecycle of rewards, and the concrete rules that determine feature enablement or behavior changes in the larger system. This domain directory therefore serves as the authoritative source for referral-related business rules that upstream application layers (application/services/UI) will rely on when deciding product behavior driven by referrals.


### File Organization

Files are organized by feature area (referrals) and grouped into a domain subdirectory to keep business models and interpretation logic centralized and independent from application or infrastructure concerns. Core domain model(s) and business-rule implementations live here so other layers can import a stable API.
