## Overview

This directory groups all code related to the referrals feature. At the root level there are no documented files; the authoritative domain-level implementation is located in the domain/ subdirectory where the documented file referral_reward.dart defines the referral reward model and the logic used to interpret how granted referral rewards affect product features. The domain/ folder holds domain models and business logic that represent and interpret referral rewards.

In addition to domain/, this directory contains application/, data/, and presentation/ subdirectories (listed but not documented here). application/ is intended for orchestration and use-case code that coordinates domain logic with data and presentation layers. data/ is intended to contain persistence, API clients, and repository implementations that supply referral data to the domain layer. presentation/ is intended to contain UI-related components or view models that present referral information to users. Together these layers separate responsibilities: domain encapsulates rules and models (such as referral_reward.dart), application coordinates flows, data persists and retrieves referral data, and presentation adapts domain outputs for the user-facing surface.
